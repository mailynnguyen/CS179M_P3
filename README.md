# CS179M_P3

This project is attempts to legally balance a ship based on the equation |Pr - Sr| < ( Sum(Po, So) * 0.10 ). Po and So represent the initial sides of the ship, P being the left side and S being the right side, and Pr represents the new left side and Sr represents the new right side. The algorithm takes in a text file with coordinates, weights, and names of respective weights, and turns it into a 2D array. The algorithm only moves containers from the heavier side of the ship to the lighter side of the ship. The algorithm test moves a container and then checks if that move resulted in a better/lighter ship. The move that makes the ship the lightest/most balanced becomes the official move. This continues until the ship is balanced.
